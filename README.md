# TapeCapture

TapeCapture は、VHSデッキやその他のキャプチャーデバイスから映像を録画するためのアプリケーションです。
キャプチャデバイスからの映像を監視し、映像再生中か判定することで自動で録画開始・録画停止する機能を提供します。

> [!IMPORTANT]
> TapeCapture を使用するには FFmpeg が必要ですが、アプリケーションには同梱されていません。
> FFmpeg を別途インストールし、`ffmpeg` コマンドを `PATH` から実行できるようにするか、アプリケーション起動前に環境変数 `TAPECAPTURE_FFMPEG_PATH` に FFmpeg 実行ファイルのパスを設定してください。

## ダウンロード

TapeCapture は Windows 11 環境で動作確認を行っています。

macOS および Linux については、ビルドおよびアプリケーションの起動を確認していますが、各機能の動作については十分な検証を行っていません。環境やキャプチャーデバイスによっては、一部の機能が正常に動作しない可能性があります。

### Windows

Windows 向けインストーラーは [GitHub Releases](https://github.com/shunmoridev/tape-capture/releases) からダウンロードできます。
FFmpeg は同梱されていないため、別途インストールしてください。現在のリリースビルドはコード署名されておらず、Windows SmartScreen の警告が表示される場合があります。

### Mac/Linux

現在、TapeCapture は macOS および Linux 向けのバイナリを提供していないため、利用するにはソースコードからのビルドが必要です。

ビルドには以下の開発環境が必要です。導入方法については、それぞれの公式ドキュメントを参照してください。

- Node.js
- pnpm
- Rust
- Tauri

リポジトリを取得後、以下のコマンドでビルドできます。

```bash
pnpm install
pnpm tauri build
```

Linux 環境では、日本語などの文字が正常に表示されない場合があります。
その場合は、WebKitGTK で利用可能な適切なフォントをインストールしてください。

Ubuntu / Debian 系では、例えば以下のコマンドで Noto CJK フォントを導入できます。

```
sudo apt install -y fonts-noto-cjk
fc-cache -fv
```

## 主な機能

* キャプチャーデバイスの映像を常時表示し、プレビュー音声を独立して制御できます。
* 映像入力に対応すると推測される音声入力を自動的に提案し、ユーザーが変更または無効化できます。
* コンテンツの開始・終了を検出すると、自動的に録画を開始・停止します。
* 開始確認中の映像を録画の先頭に含め、コンテンツ冒頭の欠落を防ぎます。
* 自動検出を使用したくない場合は、いつでも即時手動録画を利用できます。
* 録画ファイルを MKV または MP4 で保存し、完成した動画を検証してから復旧可能な元ファイルを削除します。
* 保存先の空き容量、次に使用されるファイル名、録画状態、ファイル保存の進行状況を表示します。

## 基本的な使い方

1. USBキャプチャーデバイスを介して再生デッキを接続します。
2. 映像入力を選択し、プレビュー画面で提案された音声入力を確認します。
3. 出力フォルダー、コンテナ形式、品質、録画モードを選択します。
4. 自動録画を開始してテープを再生します。TapeCapture はコンテンツの開始を待機し、各セクションの開始・終了に合わせてファイルを作成します。
5. 取り込み作業が終了したら自動録画を停止します。すでに保存処理中のファイルについては、バックグラウンドで処理が継続されます。

録画の開始・停止を直接操作したい場合は、即時録画を使用してください。
検出タイミングや、開始確認中の映像をどの程度含めるかは、録画設定から変更できます。

> [!TIP]
> 自動判定の傾向は、VHSデッキやキャプチャーデバイス、テープごとの無映像画面・ノイズ・音声状態によって変わります。
> キャプチャーデバイス、再生機器、テープ、ドライバーなどの組み合わせは多岐にわたるため、すべての環境で自動判定や録画が完全に動作することを保証するものではありません。
> 大切な録画の前に、開始・終了を含む短い区間を数回試し録画し、意図した位置でファイルが区切られるか確認してください。
> 合わない場合は判定時間を調整するか、即時録画を使用してください。

## 自動録画の仕組み

自動録画では、映像と音声から確認できる特徴をもとにコンテンツの有無を判定します。
再生コンテンツに暗い映像、無音、静止画などが非常に長く続く場合、
録画が想定とは異なるタイミングで停止することがあります。

開始確認中の映像を含める時間や、検出を確定するまでの時間は設定できるため、判定にある程度の余裕を持たせることができます。
正確な位置で録画を開始・終了したい場合は、ライブプレビューを確認しながら即時録画モードを使用できます。

開始を確定した場合は、最初に映像を検出した付近から録画ファイルに含め、
それより前の明らかな無映像区間は除外します。エンコード単位の安全余白として、検出直前が短く残る場合があります。
終了を確定した場合は、確認に使った無映像区間をファイル末尾から除外します。
確認中に映像または有効な音声が戻った場合は終了せず、その短い間も同じ録画に残します。

## 開発

TapeCapture は、Tauri 2、React、TypeScript、Rust、Web `MediaStream`、FFmpeg を使用しています。

システムアーキテクチャについては [`docs/en/ARCHITECTURE.md`](docs/en/ARCHITECTURE.md)、インターフェースの設計方針については [`docs/en/UI_DESIGN.md`](docs/en/UI_DESIGN.md) を参照してください。

開発には Node.js、pnpm 11、Rust、Tauri の各プラットフォーム向け前提環境、および `PATH` から利用可能な FFmpeg、または `TAPECAPTURE_FFMPEG_PATH` で設定された FFmpeg が必要です。

```powershell
pnpm install
pnpm tauri dev
```

主なチェックコマンド：

```powershell
pnpm build
pnpm test:ts
pnpm test:rust
```

リリース作成手順は [`docs/en/RELEASING.md`](docs/en/RELEASING.md) を参照してください。
